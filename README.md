# 🌸 금옥여자고등학교 대입 수시 모의면접 신청 시스템

**금옥여자고등학교** 학생들을 위한 모의면접 신청 웹페이지와 **구글 스프레드시트 실시간 연동 시스템**입니다.

---

## 🌟 주요 반영 사항

1. **소속 학교**: **금옥여자고등학교** 3학년부 (1반 ~ 9반)
2. **지원 대학교 수기 입력**:
   - 학생이 지원하는 대학교명을 제약 없이 자유롭고 정확하게 수기 입력
3. **심플한 날짜 UI (하루 vs 기간)**:
   - **하루**: 달력에서 단일 날짜 선택
   - **기간**: [시작일]과 [종료일]을 달력에서 각각 선택
4. **구글 시트 자동 분리 저장**:
   - 학생 1명이 복수 대학을 신청해도 지원 대학별로 **1개 행(Row)씩 깔끔하게 누적**되어, 계열별(인문/자연) 및 일정별 필터링이 매우 수월합니다.

---

## 🚀 구글 시트 연동 3단계 (3분 소요)

### 1단계: 구글 스프레드시트 생성 및 코드 붙여넣기
1. [Google 스프레드시트](https://sheets.new)에서 새 시트 생성 (예: `2026학년도 금옥여고 모의면접 신청명단`)
2. 상단 메뉴 **[확장 프로그램]** ➔ **[Apps Script]** 클릭
3. 기존 코드를 지우고 [`google-apps-script.js`](file:///C:/projects/form/google-apps-script.js) 파일의 내용을 전체 복사하여 붙여넣기 후 **저장(💾)**

### 2단계: 웹 앱 배포
1. 우측 상단 **[배포]** ➔ **[새 배포]** 클릭
2. 톱니바퀴 ⚙️ ➔ **[웹 앱]** 선택
   - 설명: `금옥여고 모의면접 접수`
   - 다음 사용자 권한으로 실행: `나 (선생님 계정)`
   - 액세스 권한이 있는 사용자: **`모든 사용자 (Anyone)`** ★ (학생들이 별도 로그인 없이 제출 가능)
3. **[배포]** 클릭 ➔ [액세스 승인] 절차 진행 ➔ 생성된 **웹 앱 URL** 복사

### 3단계: `index.html`에 URL 설정
1. [`index.html`](file:///C:/projects/form/index.html) 25번째 줄의 `GOOGLE_SCRIPT_URL`에 복사한 웹 앱 URL을 붙여넣기:
   ```javascript
   const GOOGLE_SCRIPT_URL = "https://script.google.com/macros/s/AKfycb.../exec";
   ```
2. 저장하면 완료!
